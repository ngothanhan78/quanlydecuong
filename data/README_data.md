# Thư mục data/

## field-schema.js — NGUỒN SỰ THẬT DUY NHẤT

File này được sinh ra TỰ ĐỘNG bởi Schema Generator Tool.
KHÔNG sửa tay file này.

### Khi nào cần cập nhật?
- Khi template Word (ĐCCT hoặc ĐCTQ) thay đổi
- Khi sheet Info hoặc Table_Info trong Google Sheet thay đổi

### Cách cập nhật:
1. Mở tools/schema-generator.html trên máy tính
2. Upload Template_ĐCCT.docx + Template_ĐCTQ.docx + BanVeThietKe_v6.xlsx
3. Bấm "Tạo field-schema.js" → Download
4. Copy file vào thư mục này (ghi đè file cũ)
5. Push lên GitHub → app tự cập nhật
